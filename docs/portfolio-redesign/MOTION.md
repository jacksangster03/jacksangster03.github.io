# Motion

Canonical raw source: `research/jack-portfolio-scrollytelling-research-plan-updated.md`.

## Motion personality

Motion should clarify transformation: raw signal becomes structure, structure becomes
decision, decision becomes evidence. It should not be permanently busy.

## Core vocabulary

- Pin only when it earns narrative focus.
- Use scroll progress for scene state changes.
- Limit each scene to a small number of moving parts.
- Prefer code-controlled overlays for factual labels, data, routes and diagrams.
- Generated video loops may sit behind accurate HTML/SVG layers.

## Reduced motion

When `prefers-reduced-motion: reduce` is active:

- Disable autoplay video.
- Show posters or static scene states.
- Replace scrubbed transformations with stacked panels.
- Preserve all content and project evidence.

## Performance constraints

- Lazy-load heavy media below the hero.
- Keep video loops short, muted and compressed.
- Do not require sound for comprehension.
- Use `ASSET-LEDGER.md` for every video, poster and generated frame.
