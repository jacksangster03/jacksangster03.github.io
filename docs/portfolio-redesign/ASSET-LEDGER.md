# Asset Ledger

Use this ledger for every generated, captured, recorded, purchased or processed asset.

## Rules

- No asset enters the site without a source and usage note.
- Generated assets are atmospheric unless paired with accurate project data overlays.
- Keep prompts, model names, settings and generation dates.
- Record compression and conversion steps for video.
- Do not commit private, NDA-sensitive or credential-bearing source material.
