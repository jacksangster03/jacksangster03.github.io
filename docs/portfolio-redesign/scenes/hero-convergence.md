# Scene: Hero Convergence

## Purpose

Introduce the portfolio thesis: science, markets and software converge into one
evidence-building practice.

## Content

- Jack Sangster.
- Biology, markets, software.
- Short positioning line.
- Links to work, GitHub, LinkedIn and email.

## Visual direction

A restrained convergence object or layered field. Labels and factual text must be HTML
or SVG, not baked into generated media.

## Acceptance criteria

- Works without motion.
- Text remains readable on mobile.
- Reduced-motion mode shows a static hero state.
