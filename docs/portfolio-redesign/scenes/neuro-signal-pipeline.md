# Scene: Neuro Signal Pipeline

## Purpose

Show biological signal becoming a computational signal pipeline.

## Candidate projects

- EEG motor imagery if ready.
- Cognix if the honest evidence is stronger at implementation time.

## Required factual layer

- Signal trace or pipeline states.
- Clear distinction between real project evidence and future direction.
- No overclaiming clinical or neuroscience capability.

## Acceptance criteria

- Reduced-motion mode presents the same steps as static panels.
- Mobile version avoids cramped waveforms and unreadable charts.
