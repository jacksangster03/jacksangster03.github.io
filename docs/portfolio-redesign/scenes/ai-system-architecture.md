# Scene: AI System Architecture

## Purpose

Show governed AI system design, routing and review.

## Candidate projects

- SEIL, with NDA-safe framing.
- Pharma automation systems where public-safe.

## Required factual layer

- Architecture diagram or route map.
- Explicit safe wording for private/NDA material.
- Evidence links only where public.

## Acceptance criteria

- No confidential implementation details.
- Project contribution is clear without exposing private code.
- Static fallback keeps the architecture readable.
