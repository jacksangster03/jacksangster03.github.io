# Scene: Biology To Computation

## Purpose

Show molecular or biochemical information becoming computational representation.

## Candidate projects

- SMILES-IUPAC Translation.
- Tox21 / DeepChem work.
- Relevant public-safe parts of SEIL only if appropriate.

## Required factual layer

- Real SMILES or molecular example.
- Tokenisation or translation step.
- Project link and evidence note.

## Acceptance criteria

- Generated imagery is atmosphere only.
- Chemical strings and project facts are accurate text/SVG overlays.
- Mobile fallback preserves the pipeline.
