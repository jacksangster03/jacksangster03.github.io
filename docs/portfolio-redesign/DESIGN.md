# Design

Canonical raw source: `research/jack-portfolio-scrollytelling-research-plan-updated.md`.

## Identity

Use a premium scientific-editorial visual system: restrained, technical, legible and
evidence-led. The site can feel cinematic, but it should not become a decorative
animation reel.

## Visual principles

- Dark technical base with controlled accent colours.
- Domain-specific accents change data and scene behaviour, not the whole identity.
- Prefer real project screenshots, code-derived visuals, SVG diagrams, Canvas or
Three.js for inspectable systems.
- Generated imagery is allowed for chapter atmosphere and posters, with provenance in
`ASSET-LEDGER.md`.

## Domain accents

| Domain | Direction |
|---|---|
| Biology | Molecular forms, sequence/token flow, scientific notation |
| Neuro | Signal traces, electrodes, spectral maps, clinical observatory tone |
| Finance | Filtering, ranking, decision pipelines, restrained chart language |
| AI/software | System architecture, routing, governance, deployment diagrams |
| Geospatial | Maps, globe layers, risk overlays, incident reporting |

## Implementation guardrails

- Keep text readable over any media.
- Avoid large decorative orbs and generic gradient-only scenes in the redesign.
- Use semantic HTML for page structure.
- Design every scene with desktop, mobile and reduced-motion states.
